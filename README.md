# Проект 'pythonProject5'

## Описание: проект представляет собой веб-приложение для онлайн-обучения.

## Установка:

1. Клонируйте репозиторий:

```commandline
    git clone https://github.com/serg-asabaev/gjango_rest_framework
```

2. Установите зависимости:

```commandline
    poetry install
```

## Модули и функции

1. manage.py - стандартная точка запуска приложения на Django.

Пример использования для запуска сервера на локальном порте 8080:
```commandline
   python manage.py runserver 8080
```

2. Приложение catalog реализует взаимодействие пользователя с проектом, отправляет пользователю шаблоны html-страниц.

## Ендпоинты

1. Регистрация и авторизация
   1. /users/token/ - получение токена авторизации. В теле post-запроса необходимо прописать json-строку вида:
    ```json
    {
      "email": "email пользователя",
      "password": "пароль пользователя"
    }
    ```
   2. /users/register/ - регистрация пользователя. В теле post-запроса необходимо прописать json-строку вида:
    ```json
    {
    "email": "email пользователя",
    "password": "пароль пользователя"
    }
    ```
2. Платежи
    1. users/payment/ - список платежей, 0 - идентификатор оплачиваемого курса
    2. users/payment/create/ - создание платежа
    ```json
    {
      "paid_course": 0
    }
    ```
3. Работа с уроками
   1. lesson/create - создание урока
   2. lesson/list - вывод списка уроков
   3. lesson/update/pk - обновление урока где pk это id урока
   4. lesson/delete/pk - удаление урока где pk это id урока
   5. lesson/pk - просмотр урока где pk это id урока
   Формат тела запроса:
    ```json
    {
      "title": "название",
      "description": "Описание",
      "preview": "Изображение",
      "video_link": "ссылка на видео в youtube",
      "learn_course": "id курса"
    }
    ```
4. Работа с кусами
   1. /learn_course/ - с методом get - вывод списка курсов
   2. /learn_course/ - с методом post - создание курса
   3. /learn_course/id/ - с методом get - просмотр курса
   4. /learn_course/id/ - с методом put или patch- обновление курса
   5. /learn_course/id/ - с методом delete - удаление курса
   Формат тела запроса:
    ```json
    {
      "title": "название",
      "description": "Описание",
      "preview": "Изображение"
    }
    ```
5. Работа с подпиской
    subscription/create - установка/снятие отметки о подписке на курс 
Формат тела запроса:
```json
{
  "learn_course": "id курса"
}
```
